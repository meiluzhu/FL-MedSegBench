# Fed-Polyp

This dataset is constructed for polyp segmentation task with 2D endoscopic images, comprising five clients.
👉 Please click [here](https://drive.google.com/drive/folders/1Elu-mGW5DPLAFfSwZcwVoJulkZd7TrUf?usp=drive_link) to download.

## Dataset Description
The table below provides summary information.

|                   | Dataset description
| ----------------- | -----------------------------------------------
| Description       | Fed-Polyp.
| Dataset           | A total of 1448 2D endoscopic images.
| Centers           | Five client data sources: CVC-300 with 60 images, CVC-ClinicDB with 612 images, CVC-ColonDB  with 380 images, EndoTect with 200 images, and ETISLarib-PolypDB  with 196 images.
| Task              | Polyp segmentation task.
